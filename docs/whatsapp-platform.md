# WhatsApp Platform

The WhatsApp platform supports webhook verification, inbound messages, outbound text, template readiness, delivery status tracking, conversation recording, AI Concierge integration, recommendation integration, order assistance, and loyalty assistance.

## Supported Now

- Text inbound messages.
- Delivery status updates.
- Text outbound responses.
- Template message structure.
- Media readiness through webhook parser extension points.
- AI and recommendation usage through existing SALORA services.

## Not Enabled Yet

- Live production credentials.
- Payment collection.
- Full order placement.
- Voice messages.
- Media processing.

These are intentionally blocked until provider approval, operational dashboards, and production decisions are complete.
