# Operations Platform

SALORA Phase 8 adds backend readiness for executive operations. It provides aggregated visibility for orders, payments, inventory, customers, AI, WhatsApp, loyalty, notifications, and revenue.

## APIs

- `/api/intelligence/revenue`
- `/api/intelligence/customers`
- `/api/intelligence/loyalty`
- `/api/intelligence/ai`
- `/api/intelligence/operations`
- `/api/intelligence/kpis`

All routes require MANAGER or ADMIN access and return aggregate operational data only.
