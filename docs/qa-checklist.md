# QA Checklist

## Navigation

- Web nav anchors scroll to sections.
- Mobile tabs open home, menu, cart, AI, and profile.
- Product cards open product details.

## Responsiveness

- Web hero, cards, and footer fit mobile and desktop.
- Mobile cards do not clip long product names.

## Cart Flow

- Add product from details.
- Increase and decrease quantity.
- Remove item.
- Subtotal updates.

## Checkout Mock

- Customer name, phone, order type, and notes render in preview.
- Empty notes fall back to `No notes`.

## WhatsApp Message

- Includes customer, phone, order type, items, total, and notes.
- URL uses `wa.me` placeholder number and encoded text.

## Mobile Screen Flow

- Home to concierge.
- Home to offers.
- Profile to loyalty.
- Cart to checkout to confirmation.

## Accessibility Basics

- Buttons use native pressable controls.
- Web links and buttons have readable labels.
- Color contrast is checked against dark backgrounds.
