# SALORA Investor Demo Script

## Duration

5 to 10 minutes.

## Opening Story

SALORA is a premium AI-powered cafe platform. It is not only a cafe landing page. It is the foundation for a luxury hospitality ecosystem where the guest can discover the brand, receive mood-aware recommendations, build an order, preview loyalty, and place a WhatsApp-ready request.

## Web Demo Flow

1. Open the landing page and pause on the hero.
2. Explain the promise: taste meets intelligence.
3. Scroll through Story to show hospitality, mood, craft, and technology.
4. Show Signature Drinks, Matcha, and Dessert Pairings.
5. Point out the restrained luxury visual system: matte black, warm gold, cream, matcha, and soft depth.

## Mobile Demo Flow

1. Open the Expo app home screen.
2. Show the featured Iced Matcha Vanilla and quick category chips.
3. Open the menu and filter categories.
4. Open a product details screen, change quantity, and add to cart.
5. Open cart, adjust quantity, and continue to checkout.
6. Fill name, phone, order type, and notes.
7. Show the WhatsApp message preview and confirmation timeline.

## AI Concierge Demo Flow

1. Open Concierge.
2. Try `cold`.
3. Try `sweet`.
4. Try `dessert pairing`.
5. Explain that Phase 1.5 uses local transparent logic while the interface is ready for future model-powered recommendations.

## Loyalty Vision

Show loyalty preview: points, rewards, and VIP status. Explain that it is a product foundation for repeat visits, personalized offers, and high-value customer relationships.

## Future Roadmap

- Supabase database and authentication.
- Real admin dashboard.
- Real order management.
- WhatsApp Cloud API.
- AI API integration.
- Payment options.
- Loyalty engine.
- Analytics and operational reporting.

## Closing

SALORA Phase 1.5 demonstrates a credible product spine: premium brand, ordering UX, local AI concierge, loyalty direction, and clean technical architecture ready for Phase 2.
