# WhatsApp Operations Center

## Goal

Manage templates, flows, auto replies, AI concierge, order assistance, loyalty assistance, and broadcast campaigns through the dashboard.

## Current State

SALORA has WhatsApp webhook and provider architecture. Exact dashboard metrics and no-code flow management are not yet persistent domains.

## Required Backend Activation

- Template registry.
- Flow builder schema.
- Auto-reply rules.
- Broadcast campaign lifecycle.
- Opt-in and compliance tracking.
- Message latency and delivery analytics.
- AI attribution for concierge, order assistance, and loyalty assistance.
