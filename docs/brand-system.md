# SALORA Brand System

## Direction

SALORA feels cinematic, calm, premium, and quietly intelligent. The experience should communicate boutique hospitality rather than a generic cafe template.

## Colors

- background: `#050505`
- surface: `#111111`
- surfaceSoft: `#181614`
- gold: `#C9A45C`
- goldSoft: `#E7D3A1`
- cream: `#F5EFE3`
- muted: `#9C9387`
- matcha: `#9CAF88`
- espresso: `#3A2418`

Gold is an accent for hierarchy, calls to action, and selected states. It should not dominate the interface.

## Typography

Use a clean modern sans-serif for product UI and a restrained serif only for editorial emphasis if needed. Text should feel spacious, confident, and hospitality-led.

## Tone

Warm, precise, premium, and calm. Avoid hype, fake production claims, or overexplaining technology.

## UI Principles

- Product-first screens, not decorative dashboards.
- Matte black surfaces with cream text and warm gold emphasis.
- Clear actions: WhatsApp order, add to cart, checkout, concierge prompt.
- Motion should feel soft and cinematic, never noisy.
- Every placeholder must imply a real future system.
