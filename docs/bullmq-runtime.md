# SALORA BullMQ Runtime

## Queues

- `email`
- `notifications`
- `analytics`
- `ai-tasks`
- `media-processing`

## Capabilities

- Idempotent job IDs via `idempotencyKey`.
- Exponential backoff.
- Retry limits.
- Dead-letter queue.
- Worker concurrency control.
- Queue health and metrics.

No Stripe, WhatsApp, or AI provider processors are implemented in this phase.
